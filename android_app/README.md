# Deck Hand Odds

Flutter app that computes exact opening-hand odds for a 60-card Pokemon TCG
deck. Paste a Pokemon TCG Live decklist export and it shows the top 5 most
probable 7-card opening hands, with exact percentages (multivariate
hypergeometric distribution, not a simulation estimate).

## Status / what's been verified

This environment has the standalone Dart SDK but not the full Flutter SDK
(no Android toolchain, no `flutter` command). Because of that:

- `lib/deck_parser.dart` and `lib/hand_odds.dart` are pure Dart (no Flutter
  dependency) and have been **run and verified** with `dart run
  test/verify_hand_odds.dart` -- confirmed against the Python prototype
  (same 109,000 hand compositions, probabilities summing to exactly
  1.000000, matching top-5 results).
- `lib/main.dart` (the UI) has **not** been compiled or run. `dart analyze`
  on it only reports "Flutter package not found" errors (expected, since
  Flutter isn't installed here) -- none of the 70 errors reference this
  file's own code, only missing Flutter framework symbols, which is a good
  sign it's syntactically correct. But it needs an actual `flutter run` to
  confirm the widget tree behaves as intended.
- The `android/` and `ios/` native project folders don't exist yet -- they
  get generated by `flutter create .`, which requires the real Flutter SDK.

## Setup

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. From this directory, run:
   ```
   flutter create .
   ```
   This generates the missing `android/`, `ios/`, and other platform
   scaffolding around the existing `lib/` and `pubspec.yaml` files.
3. `flutter pub get`
4. `flutter run` (with a device/emulator connected, or `flutter run -d chrome`
   to sanity-check the UI in a browser first)

## Project layout

```
lib/
  deck_parser.dart   -- parses PTCG Live decklist paste text -> {name: count}
  hand_odds.dart      -- exact hand-probability math (hypergeometric)
  main.dart            -- Flutter UI (paste box, calculate button, results list)
test/
  verify_hand_odds.dart  -- standalone verification script (see Status above)
```

## Known limitations / next steps

- Only computes the **opening 7-card hand**. Turn 2/3 draws depend on what
  you actually played turn 1 (which cards you searched, evolved, etc.), so
  they need the turn-by-turn simulation logic from this repo's
  `simulate_match.py` ported over, not the pure-combinatorics approach.
- The parser strips the trailing set-code + number (e.g. "BLK 57") and only
  keys on card name. Two different prints of the same-named card are treated
  identically, which is correct for hand-odds math but means the app has no
  card metadata (HP, attacks, images) beyond what's typed in.
- No manual card picker yet -- paste-only, per the initial scope.
